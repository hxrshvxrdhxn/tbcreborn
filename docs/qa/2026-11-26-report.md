  - `label-content-name-mismatch` on cookie banner consent buttons (`ariaAcceptLabel` mismatching visible text `"Accept All"`).
- **Remediation**:

- **Final Result**: **0 critical, 0 serious, 0 moderate violations**.
- **Keyboard Navigation**: Confirmed visible `#A7EBC8` mint focus-visible outline rings on all focusable elements during Tab traversal.

### 3.5 Negative & Positive Form Flows (8 Tests)
- **Negative Flows against Production** (`https://turbobytesconsulting.com`):
  - Empty submission: Blocked client-side and server-side with 400 response.
  - Invalid email formatting: Immediate accessible error alert.
  - Honeypot trap (`website` field filled): Request silently dropped; zero spam entries saved.
  - XSS payload (`<script>alert(1)</script>`): Stored safely as escaped plain text; no script execution.
  - Double-click debouncing: Disabled submit button prevents duplicate API calls.
  - Free AI Visibility empty submission: Blocked with appropriate field validation.
- **Positive Flows against Local Dev** (`http://localhost:7000`):
  - Contact form valid submission: Persisted to `ContactQuery` table in database.
  - Free AI Visibility Check valid submission: Persisted to database with `"AI Visibility Check"` service tagging.

### Performance Optimizations Implemented

1. **Third-Party Script Deferral (`components/DeferredAnalytics.tsx`)**:
   - Google Tag Manager (`GTM-W6MCQF5V`), Google Analytics (`G-1H5E3Y9YRF`), and Microsoft Clarity (`wy3ihoq9t1`) are deferred until first user interaction (`scroll`, `click`, `touchstart`, `mousemove`, `keydown`) or 30-second idle timer.
   - Fixed Microsoft Clarity DOM-clobbering runtime error (`TypeError: a[c] is not a function`) caused by `<script id="clarity">` clobbering the global `window.clarity` function stub.
   - Removed eager Google Tag Manager and Clarity script tags from initial page load and layout.

2. **Native Lightweight Cookie Banner (`components/CookieBanner.tsx`)**:
   - Replaced third-party `react-cookie-consent` library with a lightweight native React component, eliminating third-party JS bundle weight and layout reflows during hydration.
   - Retains exact design, ARIA accessibility labels, and consent event dispatching.

3. **Elimination of Next.js Link Over-Prefetching**:
   - Disabled eager background prefetching (`prefetch={false}`) across Navigation, Footer, Mobile Action Bar, Sticky CTA, and page hero/offer/product links.
   - Prevents 10-16 simultaneous background route fetch and RSC hydration tasks from saturating mobile CPU during initial paint.

4. **HeroLines Canvas Optimization (`components/HeroLines.tsx`)**:
   - Mobile and reduced-motion viewports render a crisp single still frame (no continuous 30fps animation loop on mobile CPU).
   - Reduced mobile line complexity by 70% and doubled step size, cutting canvas draw overhead by 80% with zero visible fidelity loss.
   - Lowered canvas device pixel ratio to 1x on mobile devices.
   - Deferred canvas initialization until after first paint (`requestAnimationFrame` + `setTimeout`).

5. **Scroll & Layout Reflow Elimination**:
   - Removed synchronous layout reads and scroll event listeners on mobile viewports (<1024px) in `Navigation.tsx` (floating header is desktop only).
   - Disabled mobile scroll listeners on `BackToTop.tsx` and removed expensive `backdrop-filter: blur(...)` from `StickyCta.tsx`.
   - Optimized `Reveal.tsx` to use standard asynchronous `IntersectionObserver` in `useEffect` (zero forced reflows / `getBoundingClientRect` layout thrashing) and bypassed on mobile viewports.
   - Replaced expensive unindexed CSS attribute substring selectors (`[class*="from-forest"]`) and `:has()` relational selectors with direct class selectors, and scoped `text-wrap: balance` to desktop viewports (`@media (min-width: 768px)`).

6. **Lenis Smooth Scroll Dynamic Import (`components/SmoothScrollProvider.tsx`)**:
   - Dynamically loaded `ReactLenis` only for desktop fine-pointer devices (`(pointer: fine) and (min-width: 1024px)`).
   - Completely omits the Lenis JavaScript physics engine from mobile client bundles, restoring zero-CPU hardware-accelerated momentum scrolling.

7. **Analytics Beacon Deferral (`components/VisitBeacon.tsx`)**:
   - Suppressed visit beacons on localhost and deferred production beacon calls by 3 seconds so analytics never contend with critical rendering path metrics.
